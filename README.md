# TypeScript-Practice
Practice TypeScript from scratch.
What is Typescript:
Typescript is a superset of Java script - it adds extra features to java script.
It compiles (Converts) into Java script, so that it runs anywhere Java script does.
I.e., writing a script in the Typescript lang, it converts code to the Java script and it executes.
Typescript files end with extension “.ts”  (instead of “.js”).
How Typescript works:
Write code in typescript (.ts files)
The typescript compiler converts it  into javascript (.js files).
	Typescript .ts → Typescript compiler (converts into) → Javascript .js
Javascript runs in web applications, Node js or any other JS environments.
Typescript vs Javascript:
All java script code works in Type script too!.
Typescript just adds additional features like types to make coding safer and easier.
It has Type safety i.e, unable to change the type of a value of a variable one it is declared.
Ex: Javascript:
	Var x=20; - declared numeric value.
	Var x=”satish”; - possible to change to string variable.
Typescript:
	Var x=20; - declared numeric value.
	Var x=”satish”; - not allowed - throws error. Once x value is declared, unable to change type.
Set-up Typescript environment:
Node JS - Provides runtime environment - where we can run javascript (JRE)
Typescript Compiler - compile the TS code to JS code and after that we can run JS code in Node JS
VS Code Editor - Like eclipse , microsoft services using VS Code editor.
TypeScript Executor - to run the type script directly without converting ts to js.
Shortcut keys for commenting:
Single line commenting: // -> Ctrl+/ 	-Mac ->Cmd+/
Multi line commenting: /*  */ -> Shift+Alt+A	-Mac-> Shift+Option+A
Removal comment is also same as above.
